Get Started

Install Luminal Linux in 3 steps.

Deploy to physical hardware or test safely in a virtual machine.

1

Download the Single Rolling ISO

Download the official 2.34 GB ISO image accelerated globally via Cloudflare's Edge CDN.

curl -LO https://iso.luminal-linux.org/luminal-linux-latest-x86_64.iso
2

Flash to USB Drive

Write the ISO to a USB thumb drive using dd or any flashing utility (BalenaEtcher, Rufus in DD mode):

sudo dd bs=4M if=luminal-linux-latest-x86_64.iso of=/dev/sdX status=progress oflag=sync
3

Boot & Run 30-Second Installer

Boot into UEFI live mode and select [1] Install Custom Arch Linux to Disk in the Welcome app.
